EeveeSpotify Version Update Locations
=====================================

The authoritative setter for the **code** version is
**Scripts/bump-version.py**, run by `.github/workflows/bump-version.yml`
(Actions → "Bump version"). It updates these two files in one pass:

1. control
   - `Version: X.Y.Z` or `Version: X.Y.Z-beta`
     <- the .deb package version (also the IPA filename)

2. Sources/EeveeSpotify/Tweak.x.swift
   - `static let version = "X.Y.Z"` (or `"X.Y.Z-beta"`) — the runtime version

There is **no build number in the code**. The settings page shows only
`v2.0.0-beta`, and the startup log prints only the version.

README.md is **not** touched by the workflow: its version references are
maintained by hand.

Pre-release versions are supported: `2.0.0-beta`, `2.0.0-beta.1`, `2.0.0-rc.1`.
The workflow input may include a leading `v` (`v2.0.0-beta`); the script strips
it because the settings view renders `"v\(EeveeSpotify.version)"` itself and the
Debian `Version:` field does not use the prefix. The value stored in both files
is therefore without `v` (e.g. `2.0.0-beta`).

Run locally with:

    python3 Scripts/bump-version.py --version 6.6.9
    python3 Scripts/bump-version.py --version v2.0.0-beta
    python3 Scripts/bump-version.py --version 2.0.0-beta --dry-run

Why a workflow as well as the script: it validates the input, shows the diff
even when you do not want to commit, and commits with the repository identity
(zbzxbg <yuanhainigu@outlook.com>) using an English message. It is manual on
purpose — bumping a version is a release action, and a push-triggered commit
would retrigger itself.

Derived, never typed
--------------------
- `build-ipa-local.sh` and both build-ipa workflows read the version from
  control at run time (`grep -E '^Version:' control`), so an IPA cannot be
  built with a stale package version.
- The `.deb` filename and the IPA output name are derived from control.

If you add another place that shows the version, add it to
`Scripts/bump-version.py` (and this list) — do not reintroduce a "remember to
edit this by hand" step.
